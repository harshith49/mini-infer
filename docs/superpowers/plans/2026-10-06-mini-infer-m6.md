# M6 int8 weight-only quantization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Store GPT-2 transformer projection weights as per-output-channel symmetric int8 and publish actual memory, cached throughput and small-sample perplexity changes.

**Architecture:** Replace the four Linear projections in each transformer block with inference-only `Int8Linear` buffers and reconstruct one floating weight matrix per forward. Keep embeddings/tied output head, norms, biases, activations and caches FP32. Shared loader configuration enables the existing generation paths; a standard-library public sample loader and sliding-window NLL evaluator provide independent quality acceptance before paired measurements.

**Tech Stack:** Python 3.11.17, PyTorch 2.5.1, transformers 4.48.3, pytest 8.3.5, safetensors 0.8.0; no new dependency.

**Spec:** `docs/superpowers/specs/2026-10-06-mini-infer-m6-design.md` (written spec approved by the user).

## Review Focus

1. A late invalid projection or mixed converted topology must not leave earlier layers replaced — Task 1 pins complete topology/source validation and staged replacement.
2. Zero/subnormal/large finite rows must not divide by zero, overflow quantization intermediates or silently retain a floating source — Task 1 pins independent reconstruction and source-lifetime checks.
3. Download interruption/corruption/offline mode must not publish partial data or evaluate a different sample — Task 2 pins checksum, bounded response, atomic cache replacement and actionable failure.
4. Overlapping quality windows and a final partial target block must score each target once with a preceding token — Task 2 compares summed NLL/count to a literal independent oracle on tiny inputs.
5. Tied head storage, temporary reconstructed weights or a second model can distort savings/peak claims — Tasks 1/3 pin deduplicated storage and reconstruction lifetime; benchmark tests enforce one owned model and stage isolation.
